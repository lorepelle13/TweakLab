# TweakLab
TweakLab è un'utility per iOS che modifica le chiavi di ⁠MobileGestalt.plist⁠ (CacheExtra) per sbloccare funzioni avanzate (Dynamic Island, Stage Manager, TrollPad, Apple Intelligence, limit di carica) su iPhone 15–17 e iPad Pro. 📦 Assets: ⁠TweakLab.zip⁠ ⚠️ Consigliato rimanere sul firmware più basso (es. iOS 27.0.1) e non aggiornare.
